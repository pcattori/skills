# Skills

| Skill                                     | What it does                                                        |
| ----------------------------------------- | ------------------------------------------------------------------- |
| [`pr-full`](pr-full/)                     | Owns a change from implementation through a merge-ready PR          |
| [`pr-create`](pr-create/)                 | Creates PRs and writes or revises their titles and descriptions     |
| [`pr-proof`](pr-proof/)                   | Proves a change works and reports the evidence                      |
| [`pr-tend`](pr-tend/)                     | Addresses review feedback and monitors review and CI                |
| [`pr-comments`](pr-comments/)             | Sets attribution and content for PR comments posted on your behalf  |
| [`council`](council/)                     | Gets independent review from delegates on several model providers   |
| [`spec`](spec/)                           | Defines domain language and behavioral contracts, and their tests   |
| [`write-for-humans`](write-for-humans/)   | Writes Markdown that people can scan                                |
| [`write-skill`](write-skill/)             | Authors and organizes agent skills                                  |
| [`teach`](teach/)                         | Teaches a topic interactively, from first principles                |
| [`lang-typescript`](lang-typescript/)     | TypeScript tooling and code-authoring conventions                   |
| [`lang-html`](lang-html/)                 | HTML authoring preferences                                          |
| [`xstate`](xstate/)                       | Guidance for xstate, state machines, statecharts, and actors        |
| [`me`](me/)                               | Personal information, such as my identity and online profiles       |
